# Plans

One plan per **planned**-size spec, produced by `/dev-team:plan` from `docs/specs/NNNN-<name>.md`.
Small specs have no plan. The plan's `## Build Progress` checkboxes are the resume record for `/dev-team:build`.

Per-slice budget defaults to 15 commits / 2 review rounds; the Spec header can override. Exceeding a budget
is a stop-and-escalate, never a reason to keep polishing.
